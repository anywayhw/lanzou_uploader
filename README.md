# 蓝奏云批量上传工具（GUI）

一个用 Python + tkinter 编写的蓝奏云批量上传桌面工具。支持选择**一个或多个文件/文件夹**一次性上传到指定云盘目录，并保持本地目录结构；内置断点续传、失败自动重试、上传前校验、按目录分组限速等功能。

> ⚠️ 本工具仅用于个人合法备份与文件管理，请遵守蓝奏云用户协议，勿用于违规用途。

---

## 功能特性

- **多来源上传**：一次可选一个或多个文件、文件夹（macOS 原生对话框可直接框选文件+文件夹混合；Windows / Linux 用内置列表窗口分别添加）。
- **保持目录结构**：本地子目录会按原样在云盘目标目录下重建。
- **云盘目录浏览**：程序内直接浏览蓝奏云目录树，选择上传目标；目标目录**持久化复用**（下次启动自动恢复），本地来源每次启动手动选择。
- **Cookie 管理**：在「设置」弹窗填写并保存已登录的 Cookie（`phpdisk_info` / `ylogin`）；启动及修改后自动检测有效性。
- **前置校验**：目录层级（目标深度 + 本地新建层级）≤ 4 层；单文件 ≤ 100MB（蓝奏云限制）。
- **失败重试**：指数退避重试；区分「瞬时错误」（网络/限流，可重试）与「永久错误」（类型不支持等，不重试）。
- **分组限速上传**：按远程目录分组；同一目录内每批 ≤ 100 个文件、批间停顿，降低被限流概率。
- **断点续传**：重新开始时自动跳过上次已完成的文件，仅补传失败/未传部分。
- **任务日志**：可开启「上传日志」开关，每次任务生成独立 JSON 日志（含每文件状态/错误），便于查漏补缺。
- **User-Agent 设置**：支持「每次启动随机内置 UA / 指定内置 UA / 手动输入自定义 UA」三种模式，规避反爬拦截。
- **隐藏文件过滤**：默认自动忽略系统隐藏文件（`.DS_Store`、`Thumbs.db` 等），可在设置中关闭。

## 环境要求

- Python 3.8+（GUI 使用内置 `tkinter`，需完整版 Python；若提示缺 tkinter，请改用系统自带 Python 或安装 `python3-tk`）。
- 网络可访问蓝奏云（`lanzou.com`）。

---

## 安装与运行

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 运行
python3 lanzou_uploader.py
```

首次运行会自动在程序目录下生成 `config.json`（Cookie 与自定义 UA 默认均为空）。

### 依赖说明
- `requests` —— HTTP 请求
- `requests-toolbelt` —— 分块上传（`MultipartEncoder`）
- `tkinter` —— Python 标准库自带（GUI），无需额外安装

---

## 配置说明（config.json）

配置文件位于程序目录下，字段含义：

| 字段 | 说明 | 默认值 |
|------|------|--------|
| `cookie` | 已登录蓝奏云的 Cookie 字符串 | `""`（空） |
| `ignore_hidden` | 是否忽略系统隐藏文件 | `true` |
| `ua_mode` | UA 模式：`random` / `builtin:N` / `custom` | `random` |
| `ua_custom` | 自定义 UA（仅 `ua_mode=custom` 时使用） | `""` |
| `last_target_folder_id` | 上次选择的云盘目标目录 ID（持久化复用） | `-1` |
| `last_target_path` | 上次目标目录路径显示 | `根目录` |
| `last_target_depth` | 目标目录层级深度 | `0` |
| `dir_description` | 单目录上传时的目录描述 | `""` |
| `last_task` | 上次任务摘要（用于断点续传） | `null` |

> 程序会在「设置」保存、关闭窗口、上传完成等时机自动写入 `config.json`。

### 获取 Cookie
1. 浏览器登录蓝奏云网页版。
2. 打开开发者工具（F12）→「网络(Network)」或「应用(Application) → Cookie」。
3. 复制包含 `phpdisk_info` 与 `ylogin` 的完整 Cookie 字符串，粘贴到「设置 → 云盘 Cookie」中保存。

## 使用步骤

1. 打开「设置」，填入 Cookie 并保存（按钮会显示「登录有效 / 无效」）。
2. 点击 **选择上传文件/文件夹**：
   - **macOS**：弹出原生选择框，可框选文件与文件夹混合、可多选。
   - **Windows / Linux**：弹出列表窗口，用「添加文件… / 添加文件夹…」分别添加，支持混合多选。
   - 仅选单个目录时会提示填写「目录描述」；多选时该行自动隐藏。
3. 点击 **浏览目标云目录**，在云盘目录树中选择上传目标。
4. 点击 **开始上传**，观察进度与速度。失败项可在「任务日志」中查看，再次启动会自动断点续传。

## 平台说明

| 平台 | 来源选择方式 | 说明 |
|------|--------------|------|
| macOS | 原生 `NSOpenPanel` | 一次对话框即可框选「文件 + 文件夹」混合、多选 |
| Windows | 内置 Tk 列表窗口 | 用「添加文件… / 添加文件夹…」按钮混合多选 |
| Linux | 内置 Tk 列表窗口 | 同上 |

> 注：tkinter 标准文件对话框无法在单个原生框内同时多选文件与文件夹，故 Windows / Linux 保留列表窗口方案；macOS 通过系统原生 API 实现真正的单次混合多选。
